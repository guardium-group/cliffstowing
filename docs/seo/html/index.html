·How to use this plan

Each phase is a self-contained chunk of work. Do not start Phase 2 until Phase 1's exit criteria are all green.

  • Tick each task as you ship it
    Progress is saved to your browser's localStorage automatically. Close the tab and come back — your state persists.
  • Read the verification note under each task
    The VERIFY box tells you how to prove the task is actually done — not just declared done.
  • Run the exit-criteria checklist at the end of each phase
    The "Next phase" button stays locked until every exit-criteria item is ticked. This is the discipline that keeps the plan honest.
  • Look for the badges on each task
    CODE = touches the codebase · MANUAL = work outside the repo (GBP, citations, outreach) · CONTENT = writing pages or posts · TECH = infra / measurement
