# Cliff's Towing — SEO Execution Plan

Phased, checklist-driven execution plan derived from the full audit
(`cliffs-towing-seo-audit-and-use-cases.docx` in the project root).

Work through the phases in order. Each phase is a complete chunk of work —
do not start Phase 2 until Phase 1 is shipped.

---

## Goal

Take Cliff's Towing from a pre-launch site with strong technical bones but
weak information architecture to the #1–3 result for high-intent Edmonton
towing queries within 90 days of launch.

## Top 3 Levers (ranked by impact)

1. **Build dedicated service pages and location pages** — unlocks ~50+
   rankable URLs vs. the current 8.
2. **Claim and optimize Google Business Profile + run review acquisition** —
   GBP signals are ~32% and reviews ~16–20% of local pack ranking weight.
3. **Scale the blog from 4 → 20+ posts** in topic clusters that link back
   to the new service pages.

## How to use this plan

- Each phase doc is a flat checklist. Tick items as you ship them.
- Code-level tasks reference exact files and line numbers in `src/`.
- Content tasks (blog posts, page copy) list the keyword target and a
  one-line angle — drafts can be generated by asking Claude.
- Anything that requires a third party (GBP, citation directories,
  outreach) is flagged with **[manual]** so it's not lost in the
  code-heavy items.

## Definition of done per phase

A phase is "done" when:
1. Every checkbox is ticked.
2. The phase's verification section passes.
3. The next phase has been read so context is loaded before starting.
